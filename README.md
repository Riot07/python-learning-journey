MY SELF-TAUGHT PROGRAMMING JOURNEY

This repository documents my journey of learning programming on my own, one project at a time.

Instead of focusing only on tutorials and exercises, I am using projects to learn new concepts, apply them, and gradually build more complex programs. Each project represents where I was in my learning at that point.

The projects are currently beginner-level and novice, and that's intentional. I am not trying to make them look more advanced than they are. The purpose of this repository is to show the progression — from writing my first simple programs to eventually building more capable and complex projects.

WHY THIS REPOSITORY EXISTS

I want this repository to show more than finished projects.

It is a record of:

- Where I started
- What I learned
- What I struggled with
- How I solved problems
- How my code changes over time
- How the complexity of my projects gradually increases

The early projects may look simple, and they are. I'm learning.

What matters to me is that each project builds on the previous one. As I learn new concepts, I apply them in the next project and gradually move from beginner to intermediate and eventually beyond.

LEARNING PHILOSOPHY

I am following a project-based approach:

Learn a concept
    ->
Build something with it
    ->
Encounter problems
    ->
Solve them
    ->
Understand the concepts
    ->
Build the next project
    ->
Repeat

This repository will grow alongside my skills.

The goal isn't to make the first project impressive.

The goal is to make Project 20 noticeably better than Project 1.
